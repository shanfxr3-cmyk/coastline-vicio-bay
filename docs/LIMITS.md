# LIMITS — Coastline: Vicio Bay

Document real-world platform, toolchain, hardware, and Godot 4 renderer constraints here. Never fake a feature; ship a verified lower tier and log why here.

| ID | Area | Constraint / Decision | Impact & Mitigation |
|---|---|---|---|
| `L-001` | Codespace GPU | No hardware GPU in Codespace container; renders via Mesa Lavapipe software Vulkan (`VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json`) + `xvfb` | Local screenshots run slower than real phone hardware and reflect software Vulkan behavior; final FPS/thermal tuning must be validated on physical Android arm64 devices. |
| `L-002` | Mobile Renderer 3D Scaling | Godot 4.7.2 `mobile` renderer supports `SCALING_3D_MODE_BILINEAR` for `scaling_3d_scale < 1.0`, while `SCALING_3D_MODE_FSR` / `FSR2` require `forward_plus`. | `STANDARD` (`mobile`) uses bilinear 3D scaling at `0.50` Low / `0.70` Medium / `0.85` High; Android STANDARD may adapt down to `0.35` after warm-up. ULTRA uses FSR2 on MEDIUM/HIGH. The debug overlay and screenshot logs read back actual viewport scale. |
| `L-003` | Gradle JVM Memory | Godot 4.7.2 default `gradle.properties` requests `-Xmx4536m`, which triggers OOM killer in 7.8 GiB containers without swap. | `tools/build_android.sh` patches `android/build/gradle.properties` to `-Xmx2048m -XX:MaxMetaspaceSize=512m` and `org.gradle.daemon=false`. |
| `L-004` | Release Signing Secrets | `godot --export-release` fails without a release keystore (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`). | All three GitHub Secrets are configured. Runs `45548311788`, `45742203868`, and `45944165390` used release signing for both APKs/AAB; downloaded artifacts passed certificate/signature and bundletool checks. Builds still fall back explicitly to debug signing if secrets are absent. |
| `L-005` | Physical Android QA | The Codespace has no attached device, so local artifact checks cannot prove launch, multi-touch behavior, Vulkan driver compatibility, FPS, thermals, or battery use. | POCO M6 Pro 5G/6 GB is the entry-level reference: `0.3.0-p2` measured LOW 30 / MEDIUM 15 / HIGH 10 FPS. LOW passed and `B-006` is resolved; MEDIUM/HIGH are not tuned on this phone. `0.4.0-p2` cycle/fallback/uncap behavior, ULTRA, thermals, and battery still need device verification. |
| `L-006` | ReflectionProbe Shutdown | Godot 4.7.2/Lavapipe reports seven leaked texture RIDs at process finalization after a `ReflectionProbe` has rendered, even after explicit scene teardown; empty scenes and pre-render probe removal exit cleanly (`B-003`). | Runtime reflections remain enabled on MEDIUM/HIGH; LOW explicitly disables the probe for its cheaper tier. Treat as a nonfatal shutdown warning, check device logs, and retest on engine patch upgrades. |
| `L-007` | Phase 1 Character Art | Authored skeletal/facial assets and strand hair are not part of P1. | Ship real original articulated procedural rigs with joint-driven locomotion and distinct protagonist materials; replace/augment with authored skinned, facial, hair, and cloth assets in the P15 realism pass. |
| `L-008` | LOW Rendering Tier | LOW prioritises frame time over dynamic lighting: no sun shadows, dynamic streetlights, runtime reflection probe, glow, or volumetric fog; AA uses no MSAA/FXAA, geometry/water/cloud detail are reduced, and sky ambient/emissive lighting remains. | This is an explicit, functional lower tier, not a hidden quality switch. MEDIUM/HIGH progressively restore these features. No contact/blob shadow substitute is claimed. |
| `L-009` | Current Phase 2 Atmosphere | The sky uses quarter-resolution procedural cloud shading, not a raymarched volumetric cloud simulation. The continuous 24-hour cycle and TOD jumps are implemented; rain, puddles, storms, weather grading, and richer volumetric clouds are not shipped yet. | LOW applies atmosphere/radiance every 4 seconds, MEDIUM every 1 second, HIGH every 0.25 seconds to bound update spikes. Track weather/richer clouds in `P2.10`–`P2.11`. |
| `L-010` | Adaptive Resolution | Adaptive scale is limited to Android STANDARD and starts after warm-up; LOW can fall to 0.35 while MEDIUM/HIGH use higher floors. CLI `--quality` captures remain fixed for repeatable QA. | This reduces 3D pixel cost, not UI resolution or draw-call count. Physical-device thermal and visual acceptance are still required. |
| `L-011` | Hardware Classification | GPU auto-detection uses conservative known-family/model rules plus usable physical RAM, never CPU core count. Unknown GPUs or devices below 7 usable GiB default to LOW; explicit user choices remain available. | This avoids unsafe auto-upgrades but cannot perfectly rank every Android GPU. Ten-second sub-20-FPS fallback drops MEDIUM/HIGH one preset, saves the sustainable ceiling, and shows a HUD notice. |
| `L-012` | Uncapped Benchmark | The DBG FPS-cap button/F4 sets `Engine.max_fps=0` and requests V-Sync off; recapping restores the previous V-Sync mode. Android compositors/drivers may still impose a refresh ceiling. | This is a runtime diagnostic, not a persistent battery-friendly setting or a guarantee of rendering above display refresh. |
| `L-013` | Render-cost Profiling | `tools/profile_rendering.sh` measures actual Lavapipe frames with one MEDIUM feature enabled over LOW at a time. GPU architecture, thermal drift, and combined effects change costs. | Use its ranking for regression analysis only; physical preset FPS remains authoritative and MEDIUM/HIGH must not be tuned from the entry phone. |
