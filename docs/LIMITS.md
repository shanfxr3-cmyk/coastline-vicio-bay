# LIMITS — Coastline: Vicio Bay

Document real-world platform, toolchain, hardware, and Godot 4 renderer constraints here. Never fake a feature; ship a verified lower tier and log why here.

| ID | Area | Constraint / Decision | Impact & Mitigation |
|---|---|---|---|
| `L-001` | Codespace GPU | No hardware GPU in Codespace container; renders via Mesa Lavapipe software Vulkan (`VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json`) + `xvfb` | Local screenshots run slower than real phone hardware and reflect software Vulkan behavior; final FPS/thermal tuning must be validated on physical Android arm64 devices. |
| `L-002` | Mobile Renderer 3D Scaling | Godot 4.7.2 `mobile` renderer supports `SCALING_3D_MODE_BILINEAR` for `scaling_3d_scale < 1.0`, while `SCALING_3D_MODE_FSR` / `FSR2` require `forward_plus`. | `STANDARD` (`mobile`) build uses bilinear render scaling with `scaling_3d_scale` (`0.67` Low / `0.85` Medium / `1.0` High); `ULTRA` (`forward_plus`) uses `FSR2`. |
| `L-003` | Gradle JVM Memory | Godot 4.7.2 default `gradle.properties` requests `-Xmx4536m`, which triggers OOM killer in 7.8 GiB containers without swap. | `tools/build_android.sh` patches `android/build/gradle.properties` to `-Xmx2048m -XX:MaxMetaspaceSize=512m` and `org.gradle.daemon=false`. |
| `L-004` | Release Signing Secrets | `godot --export-release` fails without a release keystore (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`). | All three GitHub Secrets are configured. Run `45548311788` used release signing for both APKs/AAB; downloaded artifacts passed certificate/signature and bundletool checks. Builds still fall back explicitly to debug signing if secrets are absent. |
| `L-005` | Physical Android QA | The Codespace has no attached device, so local artifact checks cannot prove launch, multi-touch behavior, Vulkan driver compatibility, FPS, thermals, or battery use. | User approved the Phase 0 STANDARD APK on a physical phone on 2026-11-25. Expanded Phase 1 controls, performance, and ULTRA still require fresh physical-device verification. |
| `L-006` | ReflectionProbe Shutdown | Godot 4.7.2/Lavapipe reports seven leaked texture RIDs at process finalization after a `ReflectionProbe` has rendered, even after explicit scene teardown; empty scenes and pre-render probe removal exit cleanly (`B-003`). | Runtime reflections remain enabled because captures and phone gameplay work. Treat as a nonfatal shutdown warning, check device logs, and retest on engine patch upgrades. |
| `L-007` | Phase 1 Character Art | Authored skeletal/facial assets and strand hair are not part of P1. | Ship real original articulated procedural rigs with joint-driven locomotion and distinct protagonist materials; replace/augment with authored skinned, facial, hair, and cloth assets in the P15 realism pass. |
